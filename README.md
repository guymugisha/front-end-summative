# Student Finance Tracker 🎓💰

A sleek, functional, and modern web application designed to help students manage their finances efficiently. Track your income, monitor your spending, and keep your budget in check with a premium user experience.

## ✨ Features

- **📊 Dynamic Dashboard**: Instantly view your total balance and visualize your spending habits with a category-based bar chart.
- **🌓 Dark Mode**: Toggle between light and dark themes to suit your preference and reduce eye strain.
- **➕ Easy Transactions**: Add income and expenses with descriptions, amounts, categories, and dates.
- **🔍 Advanced Search & Sort**: Find specific transactions using regex-powered search and sort them by date, amount, description, or category.
- **📁 Data Persistence**: All your data is saved locally in your browser's `LocalStorage`, so it's there when you come back.
- **📥 Seed Data**: Automatically loads initial sample data (`seed.json`) if no records exist.
- **📤 Export Data**: Export your entire transaction history as a JSON file for backup or external analysis.
- **📱 Responsive Design**: Fully optimized for both desktop and mobile devices.

## 🚀 Getting Started

The Student Finance Tracker is a lightweight application built with vanilla web technologies. No installation or build steps are required.

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for better accessibility and SEO.
- **Vanilla CSS**: Custom design system with modern CSS variables and transitions.
- **JavaScript (ES6+)**: Functional logic, data management, and DOM manipulation.
- **LocalStorage API**: For browser-side data persistence.

## 📁 Project Structure

- `index.html`: The main entry point and UI structure.
- `style.css`: Modern, responsive styling including the dark mode system.
- `app.js`: Core application logic, event handlers, and data operations.
- `seed.json`: Sample transaction data for initial setup.
